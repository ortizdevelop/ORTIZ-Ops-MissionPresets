# Changelog
## 1.1.0
- **English interface** (default) with a **Russian** option: the panel, editor and messages are translated. Switch with the *Language* button in the panel or F1 → *0. Language*.
- Existing presets and settings are kept.
## 1.0.2
- Fixed for game version 0.34.6: the mod stopped working because the game renamed its mission picker (`MissionsPicker` → `MissionPicker`). Presets, auto-apply and the editor work again.
## 1.0.1
- Renamed to **ORTIZ Ops - MissionPresets** (DLL `ORTIZ-Ops-MissionPresets.dll`). Presets and settings are kept.
## 1.0.0
- First public release (GUID `ortiz.missionpresets`).
